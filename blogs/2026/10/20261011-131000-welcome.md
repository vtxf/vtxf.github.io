你好，欢迎来到 vtxf 博客。

## 我是谁

我是一名程序员，做过多年三维地理信息（GIS）软件的开发，近两年把大部分精力投向 AI Agent 与效率工具的研究。写代码之外，我对国产信创硬件（景嘉微、飞腾）、个人财富与财税合规、以及给孩子做教育资源这件事，都有持续的兴趣。

## 这个博客写什么

记录 AI、科技、财经、学习等内容，大致分四个栏目：

| 栏目 | 关注点 |
|---|---|
| AI 前沿 | Agent 架构、模型与 API、工具链实践 |
| 技术笔记 | 全栈开发、GIS 底层、环境排错与工程化 |
| 财经观察 | 财报、投资、财税合规与个人财富 |
| 学习成长 | 技术书摘、K12 教育资源、方法论 |

## 为什么开始记录

一是整理自己。写下来，才真正想清楚一个问题。二是连接同路人。这些年踩过的坑、验证过的方案，如果能帮到一个人，就值得公开。三是抵抗遗忘——工具迭代太快，很多细节不记下来，三个月后就找不回来了。

## 怎么跟上更新

文章按年月归档在 `blogs/YYYY/MM/`，推送到 main 后由 GitHub Actions 自动更新清单，页面即刻生效。你随时可以：

- 打开首页的文章列表浏览全部内容
- 在评论区或 Issues 里留下你的想法
- 收藏博客，看到感兴趣的选题一起讨论

技术会过时，但对原理的理解、对问题的拆解方式，是可以沉淀下来的。这里是 vtxf 的「长期主义」试验田——感谢路过，欢迎常来。
