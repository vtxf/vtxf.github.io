这是一篇 **Markdown 文章**，由 index.html 读取后用 marked.js 渲染。你可以直接往 `blogs/YYYY/MM/` 目录里放 `.md` 或 `.html` 文件，文章清单会自动更新。

## 写作规范

文章文件名遵循 JSL 年月结构：

```
blogs/
└── 2026/10/
    └── 20261011-131000-欢迎来到vtxf博客.md
```

- 文件名格式：`YYYYMMDD-HHMMSS-<主题名>.md`（主题名 ≤32 字符，空格用下划线）
- 文件开头使用 YAML front matter，列表页会展示其中的 `name` / `description` / `tags`

## 排版元素演示

### 代码块

```js
// Markdown 里的代码块会高亮展示
function hello() {
  console.log('Hello, vtxf-blogs!');
}
```

### 表格

| 条目形态 | 适用场景 |
|---|---|
| 单文件 `.md` | 普通文章 |
| 单文件 `.html` | 交互式页面，iframe 直接展示 |
| 文件夹模式 | 主文档 + 平级资料（代码、数据） |

### 引用

> 需要配图时，把图片放进 `<文件名>_attachments/` 目录，正文用相对路径引用即可，渲染时会自动修正路径。
