## 代码高亮

JavaScript 代码块（右上角有复制按钮，悬停代码块可见）：

```js
// 计算斐波那契数列第 n 项
function fib(n) {
  if (n <= 1) return n;
  let a = 0, b = 1;
  for (let i = 2; i <= n; i++) {
    [a, b] = [b, a + b];
  }
  return b;
}

console.log(fib(10)); // 55
```

## Mermaid 图

直接在文中写 ` ```mermaid ` 代码块即可渲染为图（按需异步加载渲染引擎）：

```mermaid
graph LR
  A[写 Markdown] --> B[push 到 main]
  B --> C[Actions 更新清单]
  C --> D[页面即刻生效]
```
